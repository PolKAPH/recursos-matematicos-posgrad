# 📚 Recursos Matemáticos para Pós-Graduação

Bem-vindo!

Este repositório reúne recursos de apoio para estudos em Matemática, organizados por área.

Aqui você encontrará, conforme o material for sendo produzido:

- 📖 Notas de estudo
- 📝 Solucionários
- 💻 Códigos
- 📚 Referências

O objetivo é simplesmente organizar e compartilhar materiais que possam ser úteis para outras pessoas.
